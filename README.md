# WattRoom desktop releases

Installers for the WattRoom desktop app: macOS, Windows and Linux.

**Get it at [wattroom.ch/download](https://wattroom.ch/download)** — the page picks the right installer for your computer and says what to click on first launch.

Nothing is developed here. The app lives in [natrontech/wattroom](https://github.com/natrontech/wattroom) (`desktop/`), and its `desktop-release` workflow publishes each `desktop-v*` tag as a release in this repository. Bug reports and ideas go to [that repo's issues](https://github.com/natrontech/wattroom/issues).

The app is a window around [wattroom.ch](https://wattroom.ch): the interface ships with the web app, so a desktop release only happens when the native shell itself changes. Licensed under the AGPL-3.0, like the rest of WattRoom.
